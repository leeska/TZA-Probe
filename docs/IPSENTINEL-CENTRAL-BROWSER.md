# 主控浏览器与 Agent 出口：架构评估

## 结论与范围

可以把 Chromium 移到独立浏览器工作进程，由 Agent 提供受限出口。
对基于出口 IP 的地区信号和浏览实验，这种方式可行；不等同于检测 VPS 本机浏览器，
也不保证改变服务商的 IP 地区或信誉。本文记录单一集中执行模式的实现边界和上线验收要求。
实现尚在验收中；未通过完整验收前不切换生产。不存在公网通用代理入口。

## 替换决定（2026-11-09）

按用户确认，正式目标改为单一集中执行模式，不保留本机浏览器双模式。
实施前的旧模式描述作为历史设计背景；上线必须先完成下面的替换验收。

- 主控持久保存节点策略、任务、预算及历史；Agent 仅提供有本机许可的反向出口。
- 独立 `tza-browser` 服务运行 Python/Playwright，systemd `PrivateNetwork=yes`。
  网络空间无外网接口，内部回环 HTTP 代理经 Unix socket 到主控 broker，再到 Agent；断线不直连。
- Unix socket 工作接口与管理员/Agent HTTP 接口分离，不携带管理凭据。任务租约、短期通道与结果提交绑定。
- Agent 端只连接固定服务目录的 HTTPS 来源，公网 DNS 全结果检查、数字 IP 固定、地址族锁定、字节预算。
- 单任务、单节点串行；观测全新 profile，实验 profile 按节点/服务/出口/配置摘要隔离，完成后必须单独干净复测。
- 删除旧日常执行页、安装组件入口与 Agent 本机 IPSentinel 调度接线。
  通用组件框架不能因删除 IPSentinel 旧产品路径而误删其他组件能力。
- 迁移工具放项目外：原配置/历史保留为旧环境，旧证据不进入新模式恢复结论；生产切换前停用旧日程并排空。

### 页面结构

沿用现有字体和主题色：浅色白 #ffffff、正文 #1d1d1f、次要 #737373、分隔 #e5e5e5、
动作 #171717、危险 #ef4444；深色使用既有令牌。不新增装饰色和卡片层级。

```text
IP 地区防护                         浏览器状态 / 刷新
[出口节点] [服务]                    Agent 许可与连接
地区证据 + 有效期 + 原因             当前任务 / 取消
[干净检测] [拉回尝试] [独立复测]
任务记录列表（执行位置、出口、阶段、结果）
设置：服务与地区 / 浏览环境 / 资源与排期
```

桌面字段两列、同高、左对齐；手机单列。关闭入口固定右上，主操作固定底栏。
本机浏览器安装、epoch/descriptor 手动授权和旧 JSON 编辑入口不再出现在新页面。

浏览器池与主控 HTTP 进程分离，可同机，但不能读取管理员凭据、数据库或 CC 签名材料。

## 链路

```text
主控任务与预算 → 隔离浏览器 worker → 每任务受限代理入口
                                      ↓ 已鉴权的反向隧道
                                Agent 出口 broker → 目标 HTTPS
```

Agent 主动连接，兼容 NAT，不要求 VPS 开放公网 SOCKS/CONNECT 端口。
会话绑定节点、地址族、配置修订、用途、任务 ID、有效期、字节与连接上限。
控制请求与数据隧道分别鉴权，凭据短期且不能跨节点复用。
不能通过普通插件声明获取任意目的地、主机命令或根权限。

## 安全与测量要求

- Chromium 网络空间只能连接本任务代理；隧道断开即失败，不回落主控直连。
- DNS 在 Agent 端解析，检查全部结果为公网地址，并固定实际连接的数字地址，防止重绑定。
- 出口 broker 仅允许配置目录批准的 HTTPS 目标、端口和地址族；禁止内网、回环、云元数据、任意 UDP 和通用转发。
- 不解密 TLS；浏览器侧处理导航/子资源，Agent 侧独立检查 CONNECT 目的地。重定向不能只依赖 route 回调。
  未批准图片、脚本及嵌入 frame 继续拦截但不把正常主页面判失败；未批准主页面/弹窗导航仍使任务失败。
- 阻断 QUIC/WebRTC 非代理出口、Service Worker 旁路和代理绕过；用网络隔离实测，不能只设置 Playwright proxy。
- 每任务独立隔离单元；按节点、出口、服务和用途隔离会话。干净观测不继承实验 Cookie。
- 前后出口回显走同一通道并符合预期 IP。IPv4/IPv6 分别锁定；两端计量，不把 HTTP 事件估计当全部隧道字节。
- Agent 保留本机许可、预算、暂停与撤销权。重启、隧道重连和补传不得重复执行实验。
- 主控 CPU/内存/磁盘开销上升，页面资源也经过主控与 VPS 之间链路；必须限制并发和总预算。

## 证据与兼容性

现有签名、descriptor、runtime fingerprint 与本机执行限制不能直接当集中执行证明。
应记录执行位置、浏览器宿主、出口 Agent、隧道会话及两端资源，生成新环境摘要。
切换模式后旧证据不能继续参与恢复确认；集中模式不能证明 VPS 本地浏览器沙箱与内存限制。
结果仍是匿名会话/页面信号，不外推到账户地区、真实终端定位或信誉恢复。
TLS、浏览器指纹、字体与运行平台来自浏览器宿主，不会因为 Agent 代理而变成 VPS 本机环境；
源 IP 可以来自 Agent，但判读与实验可比性必须用独立基线验证。

## 验收与替换顺序

1. 单节点、手动触发的隔离验收，不接触生产任务与历史。
2. 验证出口、错误地址族、DNS 重绑定、内网目标、断线、到期、撤销；目标站零旁路命中。
3. 验证重定向、附属请求拦截、证据完整性、取消/OOM/重启、重复请求与预算并发。
4. 新 Agent 签名发布；项目外脚本迁移配置与旧历史、关闭旧排期，备份后切换单一新入口。

### 本机接口与单次保护

- 主控启动参数：`--browser-socket /run/tza-browser/control.sock`。
- 运维创建 `/run/tza-browser`，属主为主控服务用户，组为 `tza-browser-control`，权限 `0750`。
  工作 socket 为 `0660`；只有主控用户和独立浏览器服务可访问。该组不允许其他登录用户加入。
- Agent 配置目录内的 `ipguard-egress.json` 为私有普通文件，字段为
  `enabled`、`allowed_ips`、`services`。默认缺失即禁用。
- NAT 主机可用 `source_ips` 将已批准的公网出口映射到本机绑定地址；只影响本机拨号，
  公网出口校验、服务域名白名单和单次任务保护不变。部署时分别核验本机地址与实际出口，
  不把云平台的私有网卡地址作为页面检测目标，也不将私有目标加入允许转发的地址范围。
- 不设每日次数或共享流量额度。主控和 Agent 都限制单次任务的总流量与截止时间，多个通道共用单次上限。
  双向流量统计不包括外层 HTTP/WebSocket/TLS 开销，不再读写每日额度记录。
- 浏览器父进程逐个启动子进程；到期或取消杀死任务进程组，systemd 控制总资源。
  独立复测使用临时会话，只有实验会话持久保存。结果文件可重试投递，过期租约不再入库。
