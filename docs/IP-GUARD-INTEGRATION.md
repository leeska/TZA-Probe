# 地区偏移检测

Google 一次检测分别记录搜索页地区和匿名条款适用地区，页面在同一 Google 行内独立显示。条款使用固定 `https://policies.google.com/terms`，不指定国家或语言参数，仅接受真实可见的国家版本；检测使用新匿名会话，在搜索之前读取条款，并确认前后出口一致。搜索验证、拒绝访问不会被条款正常覆盖；条款结果不触发自动校正。条款失败也不影响搜索判定。旧历史没有条款字段时保留原文，页面提示待检测；不迁移或伪造历史。

管理后台左侧「地区偏移检测」可直接进入同一插件工作区，无需先进入插件列表。侧栏高亮与面包屑保持一致。地区偏移检测是 Server 内置功能，不需要另装插件；检测默认不开启，按节点在工作区启用出口。

## 目标定位

新节点按当前所选 IPv4 / IPv6 的已授权公网出口 IP 查询近似定位并默认选中地区，不使用节点名称猜测、不默认美国。失败时明确提示，允许手动选择；已保存的地区不会被自动覆盖。

地图默认收起，可搜索城市、地址或地标、拖动地图后点击选点，或输入经纬度。方向键移动地图，回车选中中心。确认定位成功后自动匹配地区、语言与当地时区，显式保存后生效。手动改坐标必须重新确认，改变地区清除旧坐标。轮询不重建表单或地图、不清除搜索。

IP 查询使用 ipwho.is，只发送所选已授权公网 IP；地点搜索使用 Photon，只在点击搜索或回车时请求；坐标确认使用 OpenStreetMap Nominatim 和 TimeAPI 查询地区与时区。查询由已认证管理接口访问固定 HTTPS 服务，禁止重定向，限制响应大小和时间；搜索与逆地理查询分别每秒一次，定位缓存 24 小时、最多 512 条。打开地图时直接加载 tile.openstreetmap.org 瓦片并保留版权链接，不获取管理员设备的实际定位。服务失败不伪造结果。

瓦片图片单独使用 `referrerPolicy="origin"` 发送实际站点来源以符合 OpenStreetMap 使用要求，不发送后台路径或查询参数；全站仍使用 `same-origin` 来源策略。只加载展开地图当前可见的瓦片，移动时复用重叠图片并按动画帧合并重绘，使用原始稳定 URL 和浏览器 HTTP 缓存，不预取、不添加避缓存参数。验收必须检查实际请求来源与地图画面，不能只用 HTTP 200 或图片宽度判断成功，因为拒绝访问也可能返回可解码的图片。

选定坐标只在校正尝试中注入 Geolocation API，并仅对当前 Google / Meta 主站授权，不改变出口 IP、服务商数据库、账户地区或信誉。独立检测与复测使用干净临时上下文，不注入坐标、不授予定位权限。结果记录 geolocation_override，主控拒绝将注入坐标的中立检测当作正常证据。坐标变化后不复用旧环境结果。

## 按目标地区判断

Google 从中立首页可见页脚读取实际地区名称，以浏览器内置地区名称表（页面语言、浏览器语言和英语，支持长/短名称）识别地区代码。只接受可见、无交互链接且完整匹配地区名称的页脚区域；页面语言、时区、跳转域名、隐藏脚本或目标设置均不作为实际地区证据。多个不同地区名称冲突、验证页、无法匹配或没有地区名称时结果为未知。校正入口及带目标参数的访问不提供中立证据。

若中立首页没有提供地区且未拒绝访问或出现验证，只补充一次固定查询 Google 的中立搜索页，从其可见页脚读取地区。不设置 gl、uule 或其他目标地区参数、不使用地图坐标、不绕过验证；搜索仍无证据或被验证时保持未知。首页等待读取最多 5 秒、搜索页最多 10 秒，均受任务总期限约束。

Google 使用 google_page_country，Meta 使用 ads_library_country。实际代码等于所选目标才为正常，不等为地区偏移；目标可以是任何支持地区，包括中国或香港。状态同时显示实际和目标地区，不再围绕某个特定地区判断。Google/Meta 页面地区与 IP 注册库或账户地区是不同概念。

旧的香港重定向检测历史原文保留，但不再确认正常、不触发校正、不延后新地区检测；调度使用独立去重键补做当前目标地区检测，不改写策略、历史或数据库结构。

坐标是策略 JSON 的可选字段，旧策略和历史不改写，不需要数据库迁移；部署与任何临时迁移脚本均在项目外。

日常界面只有节点选择、检测开关、偏移时自动校正开关，以及 Google / Meta 状态列表。
每项提供一次检测操作。目标地区、IPv4/IPv6 和服务勾选直接在页面编辑，点击保存生效，不再有设置弹窗。
地区支持下拉和输入搜索；语言与时区由主控按目标地区自动匹配，多时区国家使用明确的地区默认时区。
具体出口 IP 由 Agent 报告的本机已授权地址中选择，不接受任意输入、不回退另一地址族；没有已授权出口时明确拒绝。
没有手动阶段、任务审批、资源调参或另一套管理入口。

## 执行

主控的独立隔离浏览器通过 Agent 本机批准的受限 HTTPS 出口访问服务。
Agent 不安装浏览器，也不运行旧本机插件。缺少本机出口许可时不执行。
浏览器网络空间仅有回环接口，没有绕过节点的主控直连后备路径。

开启节点检测后每 12 小时检查各已选服务，离线时跳过，恢复后补做已到期检测。
启用自动校正时，当前设置下的干净检测确认偏移才尝试一次校正，再独立干净复测。
未知、服务拒绝、验证页、过期、失败、中断和取消均不触发校正；复测仍偏移不循环重试。
链路通过持久任务身份去重，重启不会重复已完成阶段，关闭节点或修改设置会取消活动任务。

不设每日次数、每日流量或 UTC 共享额度，失败或取消不会阻止后续检测。
单次任务默认最多 120 秒和 20 MiB，同一节点一次只运行一个任务；自动校正只尝试一次，不循环重试。
首次启用只需选择目标地区、出口地址族以及已有的本机许可，不自动扩大权限。

## 状态与证据

- 正常：服务的实际页面地区与目标一致。
- 地区偏移：服务的实际页面地区与目标不一致。
- 未知：不能取得有效证据，显示原因，不回退成更早一次的正常结果。
- 待检测、检测中、正在校正、待复测、正在复测、已过期各自展示，不冒充终态。

页面地区不是服务商的 IP 数据库、账户登录地区或信誉分，校正操作完成不是恢复成功。
历史 YouTube 和旧运行记录仅保留归档，不进入当前 Google / Meta 判断。

## 交互与维护

自动更新只更新文字、状态与可用性，不重新创建节点下拉、开关或编辑表单。
每个节点的未保存草稿单独保留，切换后回来仍可继续；保存期间新增的编辑不会被旧保存响应清掉。
慢请求不能覆盖更新后的设置；离开页面会取消读取并停止轮询。
桌面列表列对齐，小屏将说明放在服务名下方。

旧本机运行器、安装/审批/暂停工作流、记录同步客户端、安装握手和运行公钥下载接口已移除。
历史数据保持独立档案，部署迁移工具在项目外执行，不作为产品兼容代码。

验证：`scripts/ip-guard-test.mjs` 覆盖跨轮询的下拉、搜索草稿、焦点与慢请求竞态；
`internal/ipguard/schedule_test.go` 覆盖自动校正、独立复测、去重、禁用和未知不执行。
