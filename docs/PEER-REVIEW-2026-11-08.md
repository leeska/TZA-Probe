# 探针项目对标与取舍

核对日期：2026-11-08。范围为下列八个项目默认分支的 README、关键实现和测试，
以及 TZA-Probe、TZA-CC、IPSentinel 当前工作树。没有运行上游服务或复现上游性能数字，
因此“低占用”“支持若干千节点”等不能视为同环境对比结论。

## 产品定位与结论

TZA-Probe 与这些项目在主机指标、在线状态、历史曲线、流量计费、告警和主题上高度重合。
单二进制、SQLite、一条命令安装已经是本项目的实现，不应再列为待补特色。

IPSentinel 不是另一套主机探针，而是可选的真实浏览器观测与受控实验组件。
它的差异是同出口基线/实验/干净复测、连续证据、Profile 隔离和共享预算，
不是浏览器打开页面就能证明改善 IP 信誉。八个项目本次检查的功能和关键路径中，
未见等价的完整证据闭环；这不是对其全部分支、插件或未来版本作不存在性保证。

建议定位：**轻量主机与网络监控为底座，Agent 内置通用管理，重型业务按需启用。**
不要为了补齐竞争表而引入默认 WebSSH、任意命令、SWAP 管理或强依赖云平台。

### 原始描述需要修正的地方

- Nezha 本次默认分支对应 `v2.6.1`，不是只确认到“有 v2”。
- `cppla/ServerStatus` 当前快照是 Go 服务端与 Python 客户端；Rust 变种是其他仓库，不能混为一个实现。
- monitor Agent 接收 `ping.tasks`，Hub 接收 `hello`、`report`、`ping.result`。
  它没有因此成为任意命令通道，但也不是绝对“只能发送、不能接收任务”。
- CF-Server-Monitor/cfsm-agent 支持动态采集及网络测试配置。
  “不提供 WebSSH/任意命令”与“没有任何主控下发”是不同的安全承诺。
- ProbeDeck 是 Node.js + SQLite 的 Cloudflare 运行环境适配，并不是 Go 单二进制移植。

## TZA 已有能力与真实缺口

| 领域 | 当前源码事实 | 应补的部分 |
| --- | --- | --- |
| 部署 | Server/Agent、SQLite、嵌入前台、接入命令、签名升级；无需部署 CC 才能做基本监控 | 新手安装后的接入/HTTPS/无数据诊断；运行功能一次确认；不同角色依赖讲清楚 |
| Agent 安全 | 出站认证、固定任务类型、插件本机禁用、签名与组件资源边界 | 真正只采集不领任务的本机模式；关闭自主升级的独立选择；按能力可验证的最小权限 |
| 历史 | 每分钟保存主机最后一次样本，主机历史最多 30 天；长窗口取每桶最后样本。TCP 已有加权桶 | 主机长期层级的 count/sum/min/max/覆盖率；平均值与末值分开；缺口保留未知 |
| 性能 | 每份报告事务更新当前指标、历史和流量；独立读池；TCP 预聚合；公开页 1 秒轻刷新与 10 秒详情刷新 | 先压测，再决定写合批、共享快照或增量推送；不重造已有网络桶 |
| 备份 | 后台一致性 SQLite 下载，包含 WAL 已提交数据；不是完整安装备份 | 包/主题配置清单与数据选择、加密归档、受验证恢复、失败回退、域名迁移 |
| 通知 | 声明式通知插件、重试、事件与投递状态；当前一个活动渠道 | 告警预设、试运行预览；有真实需求再加命名渠道及按规则路由 |
| 网络诊断 | TCP、三网回程、IPv4/IPv6、解锁、内外对照 IP 被墙检测 | 统一结果页与批量预设，不强迫用户理解 Job、绑定、Profile 和 epoch |
| 插件 | 声明式通知/目标集；通用组件/任务/资源底座；首启与 HTTP 恢复已有增量 | 一次确认的准备/审批/UI、完整生命周期和真实 Linux 验收仍未完成 |

`plugins_disabled` 和安装参数 `--no-plugin` 只关闭插件路径；普通 TCP/Route/Unlock 任务仍可领取。
因此不能把它重命名或描述成“纯监控模式”而不改变实际行为。
同样，不监听节点端口不等于主控被攻陷后没有主动任务或自动升级风险。

## 调整后的实施顺序

这是新增候选事项的优先级，不表示重新启动已清除的持续目标，也不表示以下功能已实现。

### P0：收尾现有主线，不先加新功能

1. 完成运行组件准备、精确计划审批、一次确认界面与正常 Agent 执行闭环。
2. 完成更新/回退/暂停/移除与既有 root-only 服务迁移；未知效果不能盲重试。
3. 完成当前源码的全量竞态、Linux/Chromium、桌面与窄屏验收。
4. 源码验收和生产发布分开；签名信任迁移、发布、生产数据库升级需要独立授权。

用户验收：选节点、填业务设置、看一次必要权限后确认；失败显示真实阶段和处理方式，
不手动安装依赖、重复绑定或重做已经批准的排期。通知/目标集不出现运行组件步骤。

### P1：安全默认值与可恢复运维

**纯监控模式**

- 产品层只呈现“只监控”和“监控＋探测/插件”，高级能力默认收起。
- 本机 `report-only` 策略关闭任务领取及执行、Executor/RPC 同步、组件安装及远程变更；
  心跳、指标和本机诊断继续。不删除已有待确认记录，也不把未知工作当作已经停止。
- 自升级能力独立受本机政策控制，明确“只监控＋手动更新”与允许签名自动更新的区别。
- 纯监控服务以专用非 root 用户运行；权限不足的指标显示不可用，不悄悄提权。
- 普通探测和组件管理采用能力逐项准入，主控不能反向打开本机已禁用能力。
- 已经接入的节点不自动切换策略，现有任务与未确认回执通过明确迁移处理。

验收：构造下发任务、插件请求和升级回复，Agent 在本机禁止状态下零执行、零安装；
Server 不再继续向该节点租约派发，普通指标不断；不依赖 UI 隐藏按钮作为安全边界。

**备份与恢复**

- 在现有一致性数据库快照上补完整备份清单、版本、摘要与可选加密，不自创密码算法。
- 通知凭据、Agent 凭据、MCP Key、CC 实例绑定、签名信任与浏览器 Profile 分别分类；
  不默认将登录会话、私钥或浏览器 Cookie 混入可公开分享的导出。
- Agent journal、IPSentinel 数据与预算属于节点，不冒充主控备份已经覆盖它们。
- 先预检版本、空间、路径及关联完整性；隔离目录恢复，确认切换失败可回退。
- 更换主控域名必须验证新主控身份与 TLS，保留旧地址直到收到新端真实到达确认；
  不从导入文件直接信任任意新主控地址，也不复制未完成任务后再次执行。

验收：错误密码、损坏文件、危险路径、空间不足、较新 Schema、半途断电均不损坏当前数据；
恢复后的身份、未确认记录、预算、历史与密钥处理符合用户明确选择。

### P2：长期历史与规模化

**历史分层**：先采用固定少量层级，例如分钟→小时→天，不先造通用时序数据库。
持续保留样本数、加权和、峰值、时间范围与有效覆盖；只处理已闭合窗口，聚合游标可恢复。
主机利用率、网络计数器和任务结果分别定义口径；TCP 的现有加权桶保留。
旧数据没有峰值和覆盖证据时不能补造；历史 API 版本与图表标注一并设计。

**写入与展示**：用 100/500/1000 节点和多查看者作为待测规模，不作为已经支持的宣传。
记录报告吞吐、写锁等待、WAL/磁盘、内存、查询 p95、前台流量与断线恢复。
合批限队列长度、字节与等待时间；流量账本和动作回执保持明确持久化承诺。
需要增量推送时具有序号、权限/可见性变更失效、删除消息、断线全量重建，
不能仅为降低磁盘写入而丢掉计费增量或最新离线证据。

验收：不均匀采样、空洞、重启、跨月、重复/乱序报告和慢客户端都符合原语义；
同环境对比优化前后数据，达到目标后再宣称容量，不引用上游自测替代。

### P3：降低使用成本，而非扩大权限

- 批量接入：短期、限量、可撤销的接入邀请，换取每节点独立凭据；
  不用一把永久共享密钥覆盖所有机器，不自动给新节点开启任务或插件。
- 预设：主机监控、网络质量、地区观测三个业务入口；选择节点只填一次，
  提交前显示实际作用范围；新节点不因分组变化自动获得重型运行批准。
- 通知：保留简单单出口默认值，需要时增加命名渠道和按规则路由；
  事件与每渠道投递去重分开，更新插件不静默改变通知目的地。
- HTTP/证书可用性可作为下一个原生受限探测候选；DDNS 作为主控侧可选受限集成，
  不为它创建浏览器运行组件。优先评估需求与目标地址安全策略，再开放。
- 多盘、磁盘 IO、Swap、连接数等指标按用户需求逐项补；GPU、跨系统和多站点不与首版捆绑。
- 地球、地图、个人名片等作为主题可选表现，不成为核心启动依赖。

## 通用能力归属

| 层级 | 应负责 | 不应负责 |
| --- | --- | --- |
| Agent | 采集、已支持原生探测、能力与策略执行、资源/任务/组件管理、可靠回执 | 从插件接收任意 Shell、宿主路径或永久 root 授权 |
| Probe | 历史、告警、可见性、用户意图和批准、统一状态与管理入口 | 将管理包已安装视为节点业务已经运行 |
| CC | 目录、开发者、兼容、审核、签名、分发及撤回状态 | 接收监控指标或参与每次任务执行；基本监控不要求账号绑定 |
| 业务适配器 | 精确配置、结果解释、特定健康/迁移检查 | 为每个插件重造安装、任务、资源和补传通道 |
| 声明式插件 | 通知模板、目标集等数据 | 获得脚本、数据库、端口监听或系统 RPC 权限 |
| 主题 | 展示、筛选、导航、隔离设置界面 | 执行探测、修改计费语义或绕过主控权限 |
