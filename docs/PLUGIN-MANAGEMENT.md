# 普通插件：主控管理部分与 Agent 组件

## 使用方式

插件市场不再区分「主控插件」「节点插件」。通知、目标集、IP 地区防护都在同一个插件列表。
IP 地区防护先在主控安装签名管理清单，出现在「已安装」；详情只提供「功能」「Agent」两页。
主控只保存管理元数据，不下载 Python、Chromium 等运行依赖。管理部分不是通知模板，不能执行任意代码。

Agent 页显示各 Agent 的组件状态与下一步：未安装、等待确认、处理中、已安装、待启用或不可用。
用户不填写 UUID、epoch、清单摘要，也不直接编辑运行时 JSON。审批页只展示版本、下载大小、权限、
目标 Agent 与明确操作；技术完整计划收起。所有新旧节点默认允许主控安装和运行插件，
Agent 页提供「全部允许」和每节点「不允许主控执行」，无需填写本机安装许可。

插件安装通道已合入 Agent 进程，systemd 节点只有一个 `tza-agent.service`，不再补装助手。
Agent 自动取得节点身份、钉住 CC 公钥并校验固定参考安装器；这些初始化操作不下载
Python、Chromium 或插件运行时，也不启动检测。没有插件任务时只有轻量的状态通信，不能承诺零开销。
已有标准安装节点通过签名 Agent 升级自动迁移：启动前准备必要目录和 systemd 权限，停用旧助手服务，
保留旧配置、信任公钥、安装日志与组件数据。首次迁移可能自动重启两次，不需要重跑接入命令。
未配置 Agent 升级公钥的旧节点仍需用接入命令升级 Agent 本身。OpenRC 暂时仅支持普通 Agent 功能。

关闭节点许可后，服务端拒绝新安装计划、计划批准和插件命令，不再向该节点下发排队操作。
状态同步与已开始操作的回执继续保存；不会强杀已经运行的任务。
重新允许后待处理操作可以继续；不再需要的操作应在 Agent 页取消。
如需在节点本机关闭插件通道，接入命令加 `--no-plugin`，或在 Agent 配置设置 `plugins_disabled: true`。
本机关闭会保留已安装插件及其数据，不停止独立插件服务，普通升级也不会撤销本机关闭。
恢复本机开关需删除 `/etc/tza-probe/plugins.disabled` 并清除配置中的 `plugins_disabled` 后重启 Agent。

管理部分卸载只移除主控入口，不卸载 Agent 组件，不删除历史或停止本机任务；必须单独确认。
主控管理清单更新不自动更新 Agent。离线时仍可查看已安装的管理部分及已保存的 Agent 记录。

## 内部边界

沿用 `executor.json` 和 `ipsentinel-runtime` 协议身份及既有制品签名，不把可执行组件改装成通知用 `plugin.json`。
主控使用统一市场安装 API 保存完整签名声明，读取时重新核验。安装结果明确为「管理部分」，
不能报告 Agent 已安装，也不向 CC 的 Agent 安装计数发送主控管理收据。
普通插件列表与更新清单合并管理部分；运行组件仍走精确版本、节点范围和独立批准的 Agent 通道。
卸载管理部分后旧 Agent 通道保留，可从市场重新安装管理部分接回，不静默删除用户数据。

## 交付范围

本轮实现真实主控管理部分安装/更新/移除、统一插件目录，以及简化的 Agent 状态与批准操作。
Agent 现已内置安装通道并自动配置。首次 adopt、插件运行配置与统一启停编排仍需单独实现和 Linux 验收。
这些前置能力缺失时显示明确状态，不开放假按钮、不提供远程任意命令；运行组件仍需通过签名校验。

## 验证

- 管理部分在重启与 CC 离线时保留；摘要、签名、ID 或版本异常拒绝，更新失败保留旧安装。
- 安装管理部分不下载依赖、不创建 Agent 任务、不启动浏览器；普通 ZIP 上传仍拒绝运行组件。
- 统一插件目录的分页、搜索与用途筛选正确；通知插件不获得执行权限。
- Agent 安装身份变化、过期或已有请求时拒绝新计划；批准只针对精确计划，重试不重复执行。
- 桌面与 390px 验证功能/Agent 页面、空状态、安装与卸载确认及错误提示。

### 发布前失败路径复核

- 启动前重新准备插件权限时先撤销旧就绪状态；配置读取、旧服务迁移或目录准备失败后，
  插件通道保持未就绪，普通 Agent 继续运行，不反复请求重启。损坏的状态标记明确报错。
- 自动初始化在缓存配置前检查 Probe 版本格式，避免暂时无效的身份响应被持久化后阻断后续重试。
- 回归覆盖旧 ready/restart 标记失效、首次迁移、正常重启收敛和无效版本拒绝。
- free2 重新完成全部迁移流程，并注入损坏的旧安装配置：普通 Agent 保持 active，
  插件状态退回 requested，没有重启循环；恢复配置后重启可重新就绪。
  结果保存在 `/tmp/tza-integrated-agent-20261107/result-review.json`，测试私钥与临时服务已清理。
